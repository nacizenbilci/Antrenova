# Amaç

Bu belge Antrenova'nın design principles kurallarını tanımlar.

## Temel İlkeler

- Mobile First
- API First
- Multi-Tenant
- Modüler Mimari
- Ölçeklenebilirlik
- Güvenlik Öncelikli Tasarım
- Bakımı kolay kod
- Performans odaklı geliştirme

## Kurallar

1. Alınacak tüm teknik kararlar bu belgeye uygun olacaktır.
2. İş kuralları koddan önce tanımlanacaktır.
3. Hazır tema kodları kullanılmayacaktır.
4. Tasarım sistemi merkezi olacaktır.
5. Tüm modüller birbirinden bağımsız geliştirilebilir olacaktır.
6. Veriler işletme bazında izole edilecektir.
7. Gelecekte web ve diğer istemciler aynı servis katmanını kullanacaktır.

## Kontrol Listesi

- Mimariye uygun mu?
- Ölçeklenebilir mi?
- Güvenli mi?
- Mobil kullanım uygun mu?
- Performans hedefini karşılıyor mu?
