# 18. Veri İçe/Dışa Aktarma İş Akışı (Import & Export Workflow)

> **Doküman Kodu:** WF-18  
> **Dosya Adı:** `18_IMPORT_EXPORT_WORKFLOW.md`  
> **Versiyon:** 1.0  
> **Durum:** Onaylandı  
> **Bağımlı Dokümanlar:** Background Jobs Workflow, File Upload Standards, API Standards, Audit Rules, Database Standards

---

# 1. Amaç

Bu dokümanın amacı, Antrenova platformunda gerçekleştirilecek veri içe aktarma (Import) ve dışa aktarma (Export) süreçlerinin standart iş akışını belirlemek ve veri bütünlüğünü koruyarak güvenli veri transferi sağlamaktır.

Veri aktarımı yalnızca dosya yüklemekten ibaret değildir. Dosyanın doğrulanması, veri eşleştirme, hata kontrolü, ön izleme, aktarımın gerçekleştirilmesi, sonuç raporlarının oluşturulması ve gerektiğinde geri alma işlemlerini de kapsar.

Platform genelindeki tüm veri transferleri bu standartlara uygun yürütülmelidir.

---

# 2. Temel İlkeler

Veri aktarımı aşağıdaki prensiplere uygun olmalıdır.

- Güvenli olmalıdır.
- Geri alınabilir olmalıdır.
- İzlenebilir olmalıdır.
- Tekrarlanabilir olmalıdır.
- Performanslı çalışmalıdır.

Aktarım sırasında veri kaybı yaşanmamalıdır.

---

# 3. İçe Aktarma Kaynakları

Sistem aşağıdaki kaynaklardan veri alabilmelidir.

- Excel
- CSV
- JSON
- XML (opsiyonel)
- API

Yeni veri kaynakları eklenebilir olmalıdır.

---

# 4. Dosya Doğrulama

Dosya işlenmeden önce aşağıdaki kontroller yapılmalıdır.

- Dosya türü
- Boyut
- Şablon uygunluğu
- Kodlama (Encoding)
- Başlık satırları

Geçersiz dosyalar işlenmemelidir.

---

# 5. Ön İzleme

Aktarım başlamadan önce kullanıcıya ön izleme sunulmalıdır.

Örneğin.

- Toplam kayıt
- Hatalı kayıt
- Boş alanlar
- Çakışan veriler

Kullanıcı aktarımı onaylayabilmelidir.

---

# 6. Veri Doğrulama

Her kayıt aşağıdaki kurallara göre doğrulanmalıdır.

- Zorunlu alanlar
- Veri tipi
- Business ID
- Benzersizlik
- İş kuralları

Hatalı kayıtlar raporlanmalıdır.

---

# 7. Arka Plan İşleme

Büyük veri aktarımı kullanıcıyı bekletmemelidir.

Standart süreç.

```text
Upload
↓
Validation
↓
Queue
↓
Import
↓
Report
```

Background Jobs altyapısı kullanılmalıdır.

---

# 8. Çakışma Yönetimi

Mevcut verilerle çakışan kayıtlar için politika belirlenmelidir.

Örneğin.

- Atla
- Güncelle
- Yeni oluştur
- Kullanıcıya sor

Politika aktarım başlamadan seçilebilmelidir.

---

# 9. Dışa Aktarma

Veriler aşağıdaki formatlarda dışa aktarılabilir.

- Excel
- CSV
- PDF

Export işlemleri yetki kontrolünden geçmelidir.

---

# 10. Bildirim Süreci

Uzun süren veri aktarımları tamamlandığında kullanıcı bilgilendirilmelidir.

Örneğin.

- İçe aktarma tamamlandı.
- Hata oluştu.
- Dışa aktarma hazır.

Bildirimler Notification Workflow üzerinden gönderilmelidir.

---

# 11. Hata Yönetimi

Aktarım sırasında oluşan hatalar ayrıntılı raporlanmalıdır.

Rapor.

- Satır numarası
- Alan adı
- Hata açıklaması

içermelidir.

Başarılı kayıtlar korunmalıdır.

---

# 12. Audit ve Loglama

Her veri aktarımı aşağıdaki bilgilerle kayıt altına alınmalıdır.

- Kullanıcı
- Dosya adı
- Aktarım tipi
- Tarih
- Süre
- Kayıt sayısı
- Sonuç

Aktarım geçmişi silinmemelidir.

---

# 13. API Uyumu

Import/Export API aşağıdaki süreçleri otomatik uygulamalıdır.

- Authentication
- Authorization
- Validation
- Background Jobs
- Audit

API ve kullanıcı arayüzü aynı kuralları kullanmalıdır.

---

# 14. Raporlama

Veri aktarımı aşağıdaki kriterlere göre raporlanabilmelidir.

- Başarılı kayıt sayısı
- Hatalı kayıt sayısı
- İşlem süresi
- Kullanıcı
- Dosya türü

Bu bilgiler operasyonel analizlerde kullanılmalıdır.

---

# 15. Genel Kurallar

Veri içe ve dışa aktarma iş akışı, Antrenova platformunda güvenilir veri taşınabilirliğini sağlayan temel süreçlerden biridir. Tüm veri aktarımları doğrulama aşamalarından geçirilmeli, büyük işlemler arka planda yürütülmeli, ayrıntılı hata raporları oluşturulmalı ve tüm işlemler Audit sistemi tarafından kayıt altına alınmalıdır.

Bu sayede işletmeler farklı sistemlerden güvenli veri aktarabilir, raporlarını kolayca dışa alabilir ve veri bütünlüğünü koruyarak operasyonlarını sürdürebilir.
