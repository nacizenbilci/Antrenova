# 10. MOBILE ARCHITECTURE

## Amaç

Bu doküman, Antrenova'nın iOS ve Android mobil uygulamalarının teknik mimarisini, geliştirme prensiplerini ve platform standartlarını tanımlar.

Mobil uygulama, web panelinin küçültülmüş bir kopyası değildir. Mobil kullanıcıların ihtiyaçlarına göre optimize edilmiş, çevrimdışı çalışabilen, yüksek performanslı ve cihaz özelliklerinden yararlanabilen bağımsız bir istemci olarak tasarlanmalıdır.

Bu belge, mobil uygulama geliştirme sürecindeki temel teknik standartları belirler.

---

# Mimari Felsefesi

Mobil uygulama;

- hızlı,
- güvenli,
- çevrimdışı çalışabilen,
- düşük internet hızında kullanılabilir,
- ölçeklenebilir,
- bakım yapılabilir

bir mimariye sahip olmalıdır.

Amaç yalnızca ekran göstermek değil, günlük operasyonları mobil cihaz üzerinden eksiksiz yönetebilmektir.

---

# Platform Stratejisi

İlk sürümde tek kod tabanı ile hem iOS hem Android desteklenmelidir.

Desteklenecek platformlar:

- iOS
- Android

Kod tekrarını minimuma indiren modern bir mobil mimari tercih edilmelidir.

---

# Kullanıcı Grupları

Mobil uygulama aşağıdaki kullanıcı tiplerini desteklemelidir.

- İşletme Sahibi
- Yönetici
- Resepsiyon Personeli
- Eğitmen
- Üye
- Veli (gelecek sürüm)

Her rol yalnızca kendi ekranlarını görmelidir.

---

# API İletişimi

Mobil uygulama doğrudan veritabanına bağlanmamalıdır.

Tüm veri alışverişi güvenli API katmanı üzerinden yapılmalıdır.

Authentication ve Authorization kuralları web ile aynı olmalıdır.

---

# Yerel Veri Yönetimi

Mobil uygulama sınırlı miktarda yerel veri saklayabilir.

Örneğin;

- Kullanıcı tercihleri
- Son görüntülenen kayıtlar
- Çevrimdışı işlemler
- Tema ayarları

Hassas bilgiler cihazda şifrelenmeden saklanmamalıdır.

---

# Çevrimdışı Çalışma

İnternet bağlantısı olmadığında aşağıdaki işlemler desteklenebilmelidir.

- Son görüntülenen üyeler
- Günlük ders listesi
- Günlük randevular
- Yoklama alma
- Not ekleme

Bağlantı geldiğinde senkronizasyon otomatik yapılmalıdır.

---

# Senkronizasyon

Çevrimdışı oluşturulan kayıtlar güvenli şekilde sisteme aktarılmalıdır.

Olası veri çakışmalarında kullanıcı bilgilendirilmelidir.

Senkronizasyon işlemleri arka planda çalışmalıdır.

---

# Bildirim Sistemi

Mobil uygulama Push Notification desteğine sahip olmalıdır.

Örneğin;

- Yeni randevu
- Paket bitişi
- Ödeme bildirimi
- WhatsApp gönderim sonucu
- Sistem duyuruları

Bildirimden ilgili ekrana doğrudan geçiş yapılabilmelidir.

---

# Kamera Kullanımı

Mobil cihaz kamerası aşağıdaki işlemlerde kullanılmalıdır.

- QR Kod Okuma
- Profil Fotoğrafı
- Evrak Fotoğrafı
- Makbuz Görseli

Kamera izinleri yalnızca gerektiğinde istenmelidir.

---

# Biyometrik Kimlik Doğrulama

Mobil uygulama aşağıdaki güvenlik yöntemlerini desteklemelidir.

- Face ID
- Touch ID
- Parmak İzi
- PIN

Bu özellikler kullanıcı deneyimini iyileştirir ancak sunucu tarafındaki kimlik doğrulamanın yerine geçmez.

---

# Performans

Mobil uygulama aşağıdaki hedefleri sağlamalıdır.

- Hızlı açılış
- Düşük bellek kullanımı
- Akıcı ekran geçişleri
- Optimize edilmiş görseller
- Düşük pil tüketimi

Eski cihazlarda da kabul edilebilir performans sunmalıdır.

---

# Güvenlik

Mobil uygulama aşağıdaki güvenlik standartlarını uygulamalıdır.

- HTTPS zorunlu
- Güvenli Token Yönetimi
- Hassas veri şifreleme
- Güvenli Oturum Yönetimi
- Root/Jailbreak kontrolleri (gerektiğinde)

Mobil cihazın ele geçirilmesi durumunda kullanıcı verileri korunmalıdır.

---

# Cihaz Özellikleri

İlerleyen sürümlerde aşağıdaki cihaz özellikleri desteklenebilir.

- NFC
- Bluetooth
- Konum Servisleri
- Apple Wallet
- Google Wallet
- Akıllı Saatler

Bu özellikler modüler olarak eklenebilmelidir.

---

# Güncelleme Stratejisi

Mobil uygulama sürümleri geriye dönük uyumluluğu mümkün olduğunca korumalıdır.

Zorunlu güncellemeler yalnızca kritik güvenlik durumlarında kullanılmalıdır.

---

# Test Süreci

Mobil geliştirme aşağıdaki testleri desteklemelidir.

- Unit Test
- Integration Test
- UI Test
- Gerçek Cihaz Testleri

Farklı ekran boyutlarında doğrulama yapılmalıdır.

---

# Ölçeklenebilirlik

Mobil mimari;

- Tablet Modu
- Kiosk Modu
- Apple Watch
- Wear OS
- Katlanabilir Telefonlar

gibi gelecekteki platformlara uyum sağlayabilecek şekilde tasarlanmalıdır.

---

# Değiştirilemez Kurallar

Aşağıdaki kurallar mobil geliştirme için zorunludur.

- API dışında doğrudan veritabanı erişimi yapılmayacaktır.
- Authentication ve Authorization web ile aynı kuralları kullanacaktır.
- Hassas veriler cihazda düz metin olarak saklanmayacaktır.
- Çevrimdışı işlemler senkronizasyon mekanizması ile yönetilecektir.
- Push Notification altyapısı ortak Notification Engine üzerinden çalışacaktır.

---

# Sonuç

Mobile Architecture, Antrenova'nın mobil platformlardaki teknik temelini oluşturur. Güvenli API iletişimi, çevrimdışı çalışma desteği, biyometrik doğrulama, güçlü performans ve ölçeklenebilir mimarisi sayesinde uygulama hem işletme personeli hem de üyeler için güvenilir ve profesyonel bir mobil deneyim sunacaktır.
