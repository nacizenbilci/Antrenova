# 06. Next.js Geliştirme Standartları (Next.js Standards)

> **Doküman Kodu:** DEV-06  
> **Dosya Adı:** `06_NEXTJS_STANDARDS.md`  
> **Versiyon:** 1.0  
> **Durum:** Onaylandı  
> **Bağımlı Dokümanlar:** Software Architecture, Project Structure, TypeScript Guidelines, API Standards, Performance Standards

---

# 1. Amaç

Bu dokümanın amacı, Antrenova projesinde kullanılacak Next.js geliştirme standartlarını belirlemek, App Router mimarisinin doğru kullanılmasını sağlamak ve tüm geliştiricilerin aynı geliştirme yaklaşımını benimsemesini sağlamaktır.

Next.js yalnızca sayfa oluşturmaya yarayan bir framework değildir. Sunucu tarafı render, istemci bileşenleri, Route Handler yapısı, veri getirme stratejileri, optimizasyon teknikleri ve dosya tabanlı yönlendirme sistemi birlikte değerlendirilmelidir.

Platformdaki tüm web geliştirmeleri bu standartlara uygun yapılmalıdır.

---

# 2. Temel İlkeler

Next.js geliştirmeleri aşağıdaki prensiplere uygun olmalıdır.

- App Router kullanılmalıdır.
- Server Component öncelikli düşünülmelidir.
- Gerektiğinde Client Component tercih edilmelidir.
- Performans odaklı geliştirme yapılmalıdır.
- Dosya tabanlı yönlendirme korunmalıdır.

Varsayılan yaklaşım her zaman Server Component olmalıdır.

---

# 3. App Router Kullanımı

Tüm sayfalar `app/` dizini altında oluşturulmalıdır.

Standart dosyalar.

- `page.tsx`
- `layout.tsx`
- `loading.tsx`
- `error.tsx`
- `not-found.tsx`
- `route.ts`

Eski Pages Router kullanılmamalıdır.

---

# 4. Server Components

Varsayılan olarak Server Component kullanılmalıdır.

Server Component tercih edilmesi gereken durumlar.

- Veri okuma
- Dashboard ekranları
- Listeleme sayfaları
- SEO gerektiren içerikler

Gereksiz `"use client"` kullanımından kaçınılmalıdır.

---

# 5. Client Components

Client Component yalnızca gerekli durumlarda kullanılmalıdır.

Örneğin.

- Form işlemleri
- Modal
- Dropdown
- Etkileşimli bileşenler
- Tarayıcı API kullanımı

Client Component kapsamı mümkün olduğunca dar tutulmalıdır.

---

# 6. Route Handler

API işlemleri `app/api` altında Route Handler yapısıyla geliştirilmelidir.

Kurallar.

- REST standartlarına uyulmalıdır.
- Yetkilendirme kontrol edilmelidir.
- Hata yönetimi uygulanmalıdır.
- DTO kullanılmalıdır.

İş mantığı Route Handler içerisinde yazılmamalıdır.

---

# 7. Veri Getirme

Veri getirme yöntemi kullanım senaryosuna göre seçilmelidir.

Tercihler.

- Server Fetch
- Server Action
- Route Handler
- Background Job

İstemci tarafında gereksiz veri çekilmemelidir.

---

# 8. Layout Kullanımı

Ortak kullanıcı arayüzü `layout.tsx` üzerinden yönetilmelidir.

Örneğin.

- Menü
- Header
- Sidebar
- Footer
- Breadcrumb

Tekrarlayan arayüz kodlarından kaçınılmalıdır.

---

# 9. Loading ve Error

Her kritik sayfada kullanıcı deneyimi desteklenmelidir.

Kullanılabilecek dosyalar.

- `loading.tsx`
- `error.tsx`
- `not-found.tsx`

Boş ekran gösterilmemelidir.

---

# 10. Metadata Yönetimi

Sayfa başlıkları ve metadata merkezi şekilde yönetilmelidir.

Örneğin.

- Title
- Description
- Open Graph
- Robots

Metadata sayfa bazında tanımlanmalıdır.

---

# 11. Performans

Next.js performans özellikleri etkin kullanılmalıdır.

Örneğin.

- Code Splitting
- Lazy Loading
- Dynamic Import
- Image Optimization
- Font Optimization

Varsayılan optimizasyonlar devre dışı bırakılmamalıdır.

---

# 12. Dosya Organizasyonu

Her sayfa yalnızca kendi sorumluluğunu taşımalıdır.

Sayfa altında.

- Components
- Actions
- Validators
- Hooks

gibi alt klasörler oluşturulabilir.

İş mantığı mümkün olduğunca modüllere ayrılmalıdır.

---

# 13. Kod İnceleme

Kod incelemelerinde aşağıdaki konular değerlendirilmelidir.

- Gereksiz Client Component
- Route Handler yapısı
- Layout kullanımı
- Veri getirme yöntemi
- Performans

Next.js mimarisi korunmalıdır.

---

# 14. Sürekli İyileştirme

Next.js sürümleri düzenli takip edilmelidir.

İyileştirilebilecek alanlar.

- Yeni App Router özellikleri
- Server Actions
- Cache stratejileri
- Rendering optimizasyonları
- Framework güncellemeleri

Yeni özellikler kontrollü şekilde projeye dahil edilmelidir.

---

# 15. Genel Kurallar

Next.js Standards, Antrenova web uygulamasının modern, performanslı ve sürdürülebilir şekilde geliştirilmesini sağlayan temel geliştirme kurallarını tanımlar. App Router mimarisi korunmalı, Server Component öncelikli yaklaşım benimsenmeli, Route Handler yapısı standart kullanılmalı ve Next.js'in sunduğu performans avantajlarından en üst düzeyde yararlanılmalıdır.

Bu yaklaşım sayesinde uygulama daha hızlı çalışır, bakım maliyetleri azalır, geliştirici deneyimi iyileşir ve platform büyüdükçe modern Next.js mimarisi korunmuş olur.
