# 07. React Bileşen Geliştirme Standartları (React Component Guide)

> **Doküman Kodu:** DEV-07  
> **Dosya Adı:** `07_REACT_COMPONENT_GUIDE.md`  
> **Versiyon:** 1.0  
> **Durum:** Onaylandı  
> **Bağımlı Dokümanlar:** Next.js Standards, Coding Standards, Project Structure, UI/UX Bible

---

# 1. Amaç

Bu dokümanın amacı, Antrenova projesinde geliştirilecek tüm React bileşenlerinin ortak mimari kurallara göre oluşturulmasını, tekrar kullanılabilir olmasını ve uzun vadede sürdürülebilir bir kullanıcı arayüzü yapısı oluşturmasını sağlamaktır.

React bileşenleri yalnızca ekran oluşturan yapılar değildir. Kullanıcı deneyiminin tutarlılığı, kod tekrarının azaltılması, bakım kolaylığı ve performans optimizasyonu açısından projenin en önemli yapı taşlarından biridir.

Platformdaki tüm kullanıcı arayüzü bileşenleri bu standartlara uygun geliştirilmelidir.

---

# 2. Temel İlkeler

Bileşen geliştirme aşağıdaki prensiplere uygun olmalıdır.

- Tek sorumluluk taşımalıdır.
- Yeniden kullanılabilir olmalıdır.
- Bağımsız çalışabilmelidir.
- Test edilebilir olmalıdır.
- Basit tutulmalıdır.

Her bileşen yalnızca kendi görevini yerine getirmelidir.

---

# 3. Bileşen Türleri

Platformdaki bileşenler aşağıdaki gruplara ayrılmalıdır.

- UI Components
- Layout Components
- Feature Components
- Shared Components

Her grup farklı sorumluluk taşır.

---

# 4. UI Components

Temel kullanıcı arayüzü elemanları burada bulunmalıdır.

Örneğin.

- Button
- Input
- Select
- Checkbox
- Badge
- Card
- Modal

Bu bileşenler iş mantığı içermemelidir.

---

# 5. Layout Components

Sayfa düzenini oluşturan bileşenler.

Örneğin.

- Sidebar
- Header
- Footer
- PageContainer
- Section

Bu bileşenler yalnızca yerleşimden sorumludur.

---

# 6. Feature Components

Belirli modüllere ait bileşenler ilgili modül altında bulunmalıdır.

Örneğin.

```text
features/

members/

MemberCard

MemberTable

MemberFilters
```

Başka modüllerle gereksiz bağımlılık oluşturmamalıdır.

---

# 7. Props Kullanımı

Props açık ve güçlü tiplerle tanımlanmalıdır.

Kurallar.

- Optional alanlar minimum tutulmalıdır.
- Varsayılan değerler belirlenmelidir.
- Gereksiz Props aktarımından kaçınılmalıdır.

Props yapısı sade olmalıdır.

---

# 8. State Yönetimi

Yerel State yalnızca gerçekten gerekli olduğunda kullanılmalıdır.

Tercih sırası.

- Props
- Derived State
- Local State
- Global State

Gereksiz State tanımlanmamalıdır.

---

# 9. İş Mantığı

İş kuralları Component içerisinde yazılmamalıdır.

Tercih edilen yapılar.

- Hooks
- Services
- Actions
- Utilities

Component yalnızca sunum katmanı olmalıdır.

---

# 10. Stil Yönetimi

Tasarım UI/UX Bible ile uyumlu olmalıdır.

Kurallar.

- Tutarlı boşluklar
- Standart renkler
- Ortak tipografi
- Responsive yapı

Bileşen kendi stilini kontrol etmelidir.

---

# 11. Performans

Bileşenler gereksiz yeniden render edilmemelidir.

Örneğin.

- Memoization
- Lazy Loading
- Gereksiz State azaltılması
- Doğru Key kullanımı

Performans optimizasyonu ölçülebilir olmalıdır.

---

# 12. Test Edilebilirlik

Her önemli bileşen test edilmeye uygun tasarlanmalıdır.

Kontrol alanları.

- Props
- Event
- Render
- State

DOM'a bağımlılık minimum tutulmalıdır.

---

# 13. Kod İnceleme

React bileşenleri aşağıdaki kriterlere göre incelenmelidir.

- Tek sorumluluk
- Okunabilirlik
- Props yapısı
- Performans
- Tekrar kullanılabilirlik

Kod kalitesi sürekli korunmalıdır.

---

# 14. Sürekli İyileştirme

Bileşenler düzenli olarak gözden geçirilmelidir.

İyileştirilebilecek alanlar.

- Ortaklaştırma
- Performans
- Tip güvenliği
- Kod sadeleştirme
- Tasarım uyumu

Yeni ihtiyaçlara göre bileşenler geliştirilebilir olmalıdır.

---

# 15. Genel Kurallar

React Component Guide, Antrenova kullanıcı arayüzünün sürdürülebilir ve modüler şekilde geliştirilmesini sağlayan temel geliştirme standartlarını tanımlar. Tüm bileşenler tek sorumluluk ilkesine uygun geliştirilmeli, iş mantığından ayrılmalı, tekrar kullanılabilir olmalı ve UI/UX Bible ile tam uyumlu çalışmalıdır.

Bu yaklaşım sayesinde kullanıcı arayüzü büyüse bile yönetilebilirliğini korur, geliştirici deneyimi iyileşir, kod tekrarları azalır ve platform uzun vadede yüksek kaliteli bir React mimarisine sahip olur.
