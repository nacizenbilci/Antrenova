# 38. USER MENU

## Amaç

User Menu (Kullanıcı Menüsü), kullanıcının kendi hesabı, oturumu, tercihleri ve kişisel ayarları ile ilgili tüm işlemleri tek merkezden yönetmesini sağlayan ortak bileşendir.

Bu menü yalnızca "Çıkış Yap" alanı değildir. Kullanıcının kim olduğunu, hangi işletmede çalıştığını, hangi yetkilere sahip olduğunu ve hesabıyla ilgili temel işlemleri hızlıca yönetebildiği merkezi kontrol noktasıdır.

Bu doküman, User Menu'nün içerik yapısını, davranışlarını ve tasarım standartlarını tanımlar.

---

# Tasarım Felsefesi

User Menu;

- sade,
- güven veren,
- hızlı erişilebilir,
- gereksiz seçeneklerden arındırılmış

bir yapıya sahip olmalıdır.

Kullanıcı profil işlemlerini aramak zorunda kalmamalıdır.

---

# Konum

User Menu, uygulamanın sağ üst bölümünde yer almalıdır.

Bu konum;

- masaüstü,
- tablet,
- mobil

cihazlarda mümkün olduğunca korunmalıdır.

Kullanıcı her zaman aynı noktadan hesabına ulaşabilmelidir.

---

# Profil Özeti

Menü açıldığında ilk bölüm kullanıcıya ait temel bilgileri göstermelidir.

Örneğin;

- Profil fotoğrafı
- Ad Soyad
- Kullanıcı rolü
- İşletme adı
- Şube bilgisi (varsa)

Bu bilgiler kullanıcıya sistemde hangi hesapla çalıştığını açıkça göstermelidir.

---

# Hesap İşlemleri

User Menu üzerinden aşağıdaki işlemler yapılabilmelidir.

- Profil Bilgileri
- Hesap Ayarları
- Şifre Değiştir
- İki Adımlı Doğrulama
- Oturum Yönetimi

Bu işlemler doğrudan kişisel hesabı ilgilendirir.

---

# İşletme Değiştirme

Çok işletmeli (Multi-Tenant) kullanıcılar aktif işletmeler arasında geçiş yapabilmelidir.

İşletme değişikliği;

- hızlı,
- güvenli,
- anlaşılır

şekilde gerçekleştirilmelidir.

Yanlış işletmede işlem yapılmasını önlemek için aktif işletme her zaman görünür olmalıdır.

---

# Şube Değiştirme

Çok şubeli işletmelerde kullanıcı yetkisi doğrultusunda aktif şube değiştirilebilir.

Şube değişikliği yapıldığında ekran ilgili şubenin verilerini göstermelidir.

Geçiş işlemi kullanıcıya açık şekilde bildirilmelidir.

---

# Tema Ayarları

Kullanıcı;

- Açık Tema
- Koyu Tema
- Sistem Teması

arasında seçim yapabilmelidir.

Tercihler kullanıcı hesabına bağlı olarak saklanmalıdır.

---

# Dil Tercihi

Platform çok dilli yapıya geçtiğinde kullanıcı dil tercihini User Menu üzerinden değiştirebilmelidir.

Dil değişikliği uygulama genelinde anında uygulanmalıdır.

---

# Bildirim Tercihleri

Kullanıcı kendi bildirim tercihlerini hızlı şekilde yönetebilmelidir.

Örneğin;

- Uygulama Bildirimleri
- Push Bildirimleri
- E-posta
- WhatsApp
- SMS

Bu alan detaylı ayarlara kısa yol niteliğinde olabilir.

---

# Yardım Merkezi

User Menu üzerinden Yardım Merkezi'ne erişim sağlanmalıdır.

Kullanıcı;

- Sık Sorulan Sorular
- Destek Talepleri
- Kullanım Kılavuzu
- İletişim

alanlarına kolayca ulaşabilmelidir.

---

# Geri Bildirim

Kullanıcı yaşadığı sorunları veya önerilerini doğrudan sistem üzerinden iletebilmelidir.

Geri bildirim özelliği kolay ulaşılabilir olmalı ancak ana işlemlerin önüne geçmemelidir.

---

# Lisans ve Sürüm Bilgisi

İstenildiğinde uygulamanın;

- sürümü,
- lisans bilgisi,
- güncelleme tarihi

gibi teknik bilgiler User Menu üzerinden görüntülenebilir.

Bu bilgiler daha çok yönetici kullanıcılar için faydalıdır.

---

# Oturum Yönetimi

Kullanıcı aktif oturumunu güvenli şekilde sonlandırabilmelidir.

"Çıkış Yap" işlemi menünün en alt bölümünde yer almalıdır.

Yanlışlıkla tıklamayı önleyecek kadar ayrıştırılmış olmalıdır.

---

# Güvenlik

User Menu içerisindeki tüm işlemler yetkilendirme sistemine uygun çalışmalıdır.

Kullanıcının erişim hakkı bulunmayan ayarlar gösterilmemelidir.

Profil alanı güvenlik açısından kritik bilgiler içermemelidir.

---

# Responsive Davranış

Mobil cihazlarda User Menu tam ekran panel veya alt sayfa şeklinde açılabilir.

Kullanıcı tüm temel işlemleri tek elle rahatlıkla gerçekleştirebilmelidir.

---

# Performans

User Menu hızlı açılmalı ve gereksiz veri yüklememelidir.

Sık kullanılan bilgiler önbelleğe alınabilir.

Menü açıldığında kullanıcı bekletilmemelidir.

---

# Gelecekte Genişletilebilirlik

Yeni kullanıcı özellikleri eklendiğinde mevcut User Menu yapısı korunmalıdır.

Yeni seçenekler mantıklı kategoriler altında yer almalı, menü zamanla düzensiz ve karmaşık bir yapıya dönüşmemelidir.

---

# Sonuç

User Menu, Antrenova'da kullanıcının kişisel kontrol merkezidir. Profil yönetimi, işletme ve şube seçimi, tema tercihleri, güvenlik ayarları ve oturum işlemleri tek bir standart yapı altında sunulur. Tutarlı ve sade bir kullanıcı menüsü, platformun profesyonel görünümünü güçlendirirken kullanıcıların hesaplarını güvenli ve kolay şekilde yönetmesini sağlar.
