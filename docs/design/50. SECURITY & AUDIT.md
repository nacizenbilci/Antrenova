# 50. SECURITY & AUDIT

## Amaç

Security & Audit (Güvenlik ve Denetim), Antrenova platformunun güvenliğini, kullanıcı hareketlerini ve kritik sistem olaylarını merkezi olarak yöneten modüldür.

Bu ekran yalnızca teknik güvenlik kayıtlarını göstermek için değil; işletme sahiplerinin, yöneticilerin ve sistem yöneticilerinin platform üzerinde gerçekleşen önemli işlemleri şeffaf şekilde izleyebilmesini sağlamak amacıyla tasarlanmıştır.

Bu doküman, güvenlik ve denetim modülünün mimarisini, bilgi organizasyonunu ve kullanım standartlarını tanımlar.

---

# Tasarım Felsefesi

Güvenlik ekranı;

- güven veren,
- sade,
- okunabilir,
- denetlenebilir,
- şeffaf

bir yapıya sahip olmalıdır.

Kullanıcı karmaşık teknik kayıtlar yerine anlamlı bilgiler görmelidir.

---

# Genel Yapı

Security & Audit ekranı aşağıdaki temel bölümlerden oluşmalıdır.

- Güvenlik Özeti
- Oturum Geçmişi
- Denetim Kayıtları
- Güvenlik Olayları
- API Hareketleri
- Sistem Logları

Her bölüm bağımsız olarak görüntülenebilmelidir.

---

# Güvenlik Özeti

Ekranın üst bölümünde sistemin genel güvenlik durumu özetlenmelidir.

Örneğin;

- Aktif Kullanıcı Sayısı
- Açık Oturumlar
- Son Başarısız Giriş
- Son Kritik Olay
- Güvenlik Durumu

Bu bilgiler yöneticiye hızlı genel bakış sağlar.

---

# Oturum Geçmişi

Kullanıcıların sisteme giriş hareketleri kayıt altına alınmalıdır.

Her kayıt aşağıdaki bilgileri içerebilir.

- Kullanıcı
- Tarih
- Saat
- Cihaz
- Tarayıcı
- IP Adresi
- Sonuç

Başarısız giriş denemeleri de kaydedilmelidir.

---

# Denetim Kayıtları

Kritik işlemler ayrıntılı olarak kayıt altına alınmalıdır.

Örneğin;

- Kullanıcı oluşturuldu
- Rol değiştirildi
- Şube silindi
- Finans ayarları değiştirildi
- Entegrasyon güncellendi

Her işlem geriye dönük incelenebilmelidir.

---

# Güvenlik Olayları

Risk oluşturan olaylar ayrı kategori altında gösterilmelidir.

Örneğin;

- Çok sayıda başarısız giriş
- Yetkisiz erişim denemesi
- Şüpheli IP
- API anahtarı hatası

Bu olaylar öncelik seviyelerine göre sıralanmalıdır.

---

# API Kayıtları

Dış sistemlerle yapılan kritik API işlemleri takip edilebilmelidir.

Örneğin;

- Başarılı İstek
- Başarısız İstek
- Yetkisiz İstek
- Kota Aşımı

Bu kayıtlar entegrasyon sorunlarının analizini kolaylaştırır.

---

# Sistem Logları

Uygulamanın önemli sistem olayları görüntülenebilmelidir.

Ancak teknik geliştirici logları ile yönetici ekranı birbirinden ayrılmalıdır.

Yönetim ekranında yalnızca anlamlı özet bilgiler bulunmalıdır.

---

# Filtreleme

Denetim kayıtları aşağıdaki kriterlere göre filtrelenebilmelidir.

- Kullanıcı
- Tarih
- Modül
- İşlem Türü
- Risk Seviyesi

Yoğun kayıt bulunan sistemlerde filtreleme zorunludur.

---

# Arama

Yöneticiler;

- kullanıcı adı,
- işlem adı,
- IP adresi,
- modül

üzerinden hızlı arama yapabilmelidir.

Arama performansı büyük veri kümelerinde de korunmalıdır.

---

# Veri Saklama

Denetim kayıtlarının saklama süresi işletme politikalarına göre belirlenebilmelidir.

Eski kayıtlar arşivlenebilir ancak izinsiz silinmemelidir.

Bu yapı hukuki ve operasyonel gereksinimleri destekler.

---

# Bildirimler

Kritik güvenlik olayları yöneticilere otomatik olarak bildirilebilmelidir.

Örneğin;

- Şüpheli giriş denemesi
- Yönetici hesabında değişiklik
- API anahtarı güncellemesi

Bildirimler yalnızca gerçekten önemli olaylar için oluşturulmalıdır.

---

# Yetkilendirme

Security & Audit ekranı yalnızca yetkili kullanıcılar tarafından görüntülenebilmelidir.

Standart personelin;

- IP bilgileri,
- denetim kayıtları,
- güvenlik logları

gibi hassas verilere erişimi olmamalıdır.

---

# Responsive Tasarım

Mobil cihazlarda güvenlik özeti kart yapısında sunulabilir.

Detaylı log listeleri okunabilirliği koruyacak şekilde sadeleştirilmelidir.

Kritik bilgiler öncelikli olarak gösterilmelidir.

---

# Ölçeklenebilirlik

Platform büyüdükçe;

- SIEM entegrasyonları,
- gelişmiş güvenlik analizleri,
- anomali tespiti,
- yapay zekâ destekli güvenlik

gibi özellikler aynı mimari üzerine eklenebilmelidir.

Mevcut güvenlik ekranı yeniden tasarlanmadan gelişebilmelidir.

---

# Sonuç

Security & Audit, Antrenova'nın güvenlik ve şeffaflık anlayışının merkezinde yer alan yönetim modülüdür. Kapsamlı denetim kayıtları, oturum takibi, güvenlik olayları ve merkezi log yönetimi sayesinde işletmeler platform üzerindeki kritik hareketleri güvenle takip edebilir. Bu yapı yalnızca güvenliği artırmakla kalmaz, aynı zamanda kurumsal yönetim ve denetlenebilirlik açısından da güçlü bir temel oluşturur.
