# NewPackageMemberSummary.tsx Kuralları

## Sorumluluk

Yeni paket oluşturulurken seçilen üyenin özet bilgilerini gösterir.

## Kurallar

1. Üye adı, branş, mevcut paket ve borç özeti gösterilebilir.
2. Hassas bilgiler gereksiz gösterilmemelidir.
3. Üye değişince özet anında güncellenmelidir.
4. Bileşen veri değiştirmemeli; yalnızca özet sunmalıdır.
5. Boş seçim durumunda açıklayıcı placeholder gösterilmelidir.
