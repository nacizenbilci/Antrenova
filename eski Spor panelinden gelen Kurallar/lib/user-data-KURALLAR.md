# user-data.ts Kuralları

## Sorumluluk

Kullanıcı profili, rol, işletme üyeliği ve yönetim ekranı verilerini yükler.

## Kurallar

1. Kullanıcı verisi işletme üyeliğiyle sınırlandırılmalıdır.
2. E-posta ve profil verileri gereksiz genişlikte döndürülmemelidir.
3. Rol ve izin ilişkileri tutarlı biçimde yüklenmelidir.
4. Pasif kullanıcılar açıkça işaretlenmelidir.
5. Kullanıcı oluşturma/güncelleme admin istemcisi gerektiriyorsa yalnızca sunucuda yapılmalıdır.
6. Başka işletmenin kullanıcıları listelenmemelidir.
