# Genel API Kuralları

1. Kritik kurallar sayfa bileşenlerinde dağınık olmamalıdır.
2. Web, mobil ve RFID aynı API davranışını kullanmalıdır.
3. Liste uçları filtreleme, sıralama ve sayfalama desteklemelidir.
4. API yalnızca gerekli alanları döndürmelidir.
5. Büyük raporlar gerektiğinde arka plan görevi olmalıdır.
